FORGE FITNESS — INSTALLABLE WEB APP

Included:
- index.html: the app
- manifest.webmanifest: Home Screen app metadata
- sw.js: offline cache support
- icon.svg: app icon

IMPORTANT:
A Progressive Web App must be served from an HTTPS website (or localhost) to be installable.
Opening index.html directly from Files will let you use it, but Add to Home Screen / offline app behavior may not work.

EASIEST DEPLOYMENT (GitHub Pages):
1. Sign in to GitHub and create a new public repository named forge-fitness.
2. Upload all four files from this folder to the repository's root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. Open the published HTTPS address in Safari on your iPhone.
6. Tap Share > Add to Home Screen > Add.

Your checkmarks, saved maxes, and workout log are stored on that device/browser using local storage.
They are not synced across devices. Avoid clearing Safari website data if you want to keep them.
The 1RM percentages are estimates; do not test a maximal lift just to populate the app.
